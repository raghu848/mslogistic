# MS LOGISTIC — Fast • Safe • Everywhere

Premier B2B Logistics & Global Freight Forwarding Company Website.

## 🚀 Key Features

- **Futuristic 3D WebGL Hero Background**: Infinite 3D perspective gallery tunnel built with Three.js (OriginKit `Hero 03`), displaying high-resolution air, ocean, rail, and warehouse logistics visuals.
- **Translucent White Blurry Glass Floating Navbar**: Modern glassmorphic floating HUD navigation pill with responsive mobile drawer.
- **Responsive Dual-Video Global Network Section**: Dynamic responsive video background (`make_animated_video_of_this_Ci.mp4` / `make_this_video_in_mobile_scre.mp4`) showcasing global trade routes and 6 regional hub gateways (India, Middle East, Europe, North America, Asia Pacific, and Africa).
- **17 Interactive Logistics Sections**:
  - Hero Section with Shipment Tracking Bar
  - Trust Stats Counters
  - About Us Split-screen
  - 8 Logistics Service Cards (Air Freight, Ocean Freight, Road Freight, Warehousing, Customs Clearance, Project Logistics, Express Delivery, Supply Chain Solutions)
  - 5-Step Process Journey
  - Global Network Map & Gateway Hubs
  - Why Choose MS LOGISTIC
  - 8 Industry Cargo Solutions
  - Live Interactive Tracking Modal Simulator
  - Instant Rate Quote Form with Validation
  - Client Testimonials & FAQ Accordion
  - Official Brand Visual Identity (`images/ms_logo.png`)

## 🛠️ Tech Stack

- **HTML5 / CSS3 / JavaScript (ES6+)**
- **Three.js** (WebGL 3D Tunnel Geometry)
- **OriginKit Component Systems**
- **FontAwesome 6 Icons & Google Fonts**

## 🌐 Local Development

Serve the static web app locally using `npx serve`:

```bash
cd pix
npx serve . -p 3000
```

Open `http://localhost:3000` in your web browser.
